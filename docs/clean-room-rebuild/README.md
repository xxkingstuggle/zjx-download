# Mac原生下载器：独立重建规格

本规格用于先确定 AB Download Manager 的桌面与浏览器功能，再独立开发新的 zjx-download。规格描述用户行为和外部协议，不要求沿用原来的代码、架构或界面实现。

方向版本：0.2 · 2026-10-18。允许查看旧项目，独立编写不同实现，以Mac原生交互和功能使用为目标。源码事实、作者候选和待实测项分开；本轮仍未开发新实现。

开发可使用本目录、旧项目源码、审计资料和合成验收夹具。旧实现用于理解与比对，不直接作为新业务实现搬用。参与审计的代理仍可实施；按独立设计、代码来源和实际行为核对结果。
