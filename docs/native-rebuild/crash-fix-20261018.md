# 启动崩溃修复记录

## 用户报告

- App：`zjx-download` 2.0.0 (build `20261018`)，Bundle ID `com.zjx.download`。
- 系统：macOS 27.0.1，Apple Silicon。
- 异常：`EXC_BREAKPOINT (SIGTRAP)`；主线程栈顶 `specialized GlobalSpeedModeMonitor.init(coordinator:) + 1044`。

## 定位与修改

崩溃地址映射到已安装二进制中的 `brk #1`。该指令由前一段代码在 `NSApp` 为 nil 时执行；SwiftUI 构造 App 时会先运行 `GlobalSpeedModeMonitor` 初始化器，因此初始化阶段不能假定 AppKit 全局应用对象已存在。

`GlobalSpeedModeMonitor.refresh()` 现在先检查 `NSApp`。未就绪时跳过本次采样；初始化器已注册的主线程定时器和应用激活通知会在后续继续采样。此修改不读取或迁移用户数据。
